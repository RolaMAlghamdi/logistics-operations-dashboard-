# Saudi Logistics Operations Executive Dashboard

## About The Project
This project features an interactive end-to-end executive dashboard designed to monitor and analyze 12-month performance data for Saudi Arabia logistics operations. It evaluates core operational metrics including hub risk status against an 85% SLA benchmark, vehicle type durations, total delivery volume, and fuel expenditure.

This project was developed as a final practical deliverable for the **Data Visualization & Storytelling Course** at **SDAIA Academy (أكاديمية سدايا)**.

---
